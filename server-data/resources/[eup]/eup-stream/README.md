# EUP Stream (Emergency Uniforms Pack)

Asset streaming resource for FiveM Emergency Uniforms Pack (Law & Order / Serve & Rescue).

## Directory Structure

Place your streamed clothing model assets (`.ydd`, `.ytd`, `.ymt`, `.yft`) directly into the `stream/` directory:

```text
eup-stream/
├── fxmanifest.lua
├── README.md
└── stream/
    ├── mp_m_freemode_01_mp_m_...ydd
    ├── mp_m_freemode_01_mp_m_...ytd
    ├── mp_f_freemode_01_mp_f_...ydd
    └── ...
```

## Note on FiveM Asset Streaming

Streaming custom player clothing assets in FiveM requires an active **Cfx.re Argentum (or higher)** server license key tier if your server player slot count exceeds 8 players.
